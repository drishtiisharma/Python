# 🐍 Python Learning Hub: A Visual & Practical Guide

Welcome! This repository is designed to help you master Python through **hands-on coding** and **structured visual notes**. It integrates seamlessly with **VS Code** for development and **Obsidian** for knowledge management.

## 🚀 Quick Start

### Clone the Repository
Open your terminal and clone the repo to your local machine:

```bash
git clone https://github.com/drishtiisharma/Python.git
cd Python
```

## 📝 For Notes & Knowledge Management (Obsidian)

This repo is structured to work as an **Obsidian Vault**, allowing you to visualize connections between concepts using the Graph View.

1. **Download Obsidian**: Get the latest version from [obsidian.md/download](https://obsidian.md/download).
2. **Open as Vault**:
   - Launch Obsidian.
   - Click **"Open folder as vault"**.
   - Navigate to and select the locally cloned `Python` directory.
3. **Explore**:
   - Use the **Graph View** to see how topics interlink.
   - Browse linked files to build a mental map of Python concepts.

> 💡 **Tip**: As you learn, create new notes in this vault and link them to existing topics to strengthen your understanding (as per your needs).

## 💻 For Coding & Practice (VS Code)

The repository contains two main directories for practical application:

| Folder | Purpose |
|--------|---------|
| `exercises/` | **Topic-wise exercises**. Structured practice problems organized by concept (e.g., loops, functions, OOP). |
| `learning/` | **Sandbox area**. A space for random testing, experimentation, and quick scripts. *(will be updated soon)* |

### How to Use:
1. Open the `Python` folder in **VS Code**.
2. Navigate to `exercises/` for guided practice or `learning/` for free-form coding.
3. Run, test, and iterate on your code freely.

## 🛠️ Recommended Setup

- **Editor**: [VS Code](https://code.visualstudio.com/) with the **Python Extension**.
- **Notes**: [Obsidian](https://obsidian.md/) with the **Advanced Tables** and **Excalidraw** plugins (optional, for enhanced visual learning).
