# Constraints

Constraints are simply **rules** we set for our data. They act like a security guard, stopping bad or incomplete data from entering our database.

Here are the 6 most important constraints in MySQL:

### 1. NOT NULL
*   **Rule:** The column cannot be left empty.
*   **Use when:** A field is mandatory (e.g., `username`, `password`).
*   **Code:** `name VARCHAR(50) NOT NULL`

### 2. UNIQUE
*   **Rule:** Every value in this column must be different.
*   **Use when:** we want to prevent duplicates (e.g., `email`, `phone_number`).
*   **Code:** `email VARCHAR(100) UNIQUE`

### 3. PRIMARY KEY
*   **Rule:** A combination of `NOT NULL` and `UNIQUE`. It uniquely identifies every single row.
*   **Use when:** we need a reliable way to find or update a specific record.
*   **Code:** `id INT PRIMARY KEY`

### 4. FOREIGN KEY
*   **Rule:** The value must match a `PRIMARY KEY` in another table.
*   **Use when:** we want to link two tables together (e.g., linking an `order` to a `customer`).
*   **Code:** `FOREIGN KEY (cust_id) REFERENCES customers(id)`

### 5. CHECK
*   **Rule:** The value must satisfy a specific logical condition.
*   **Use when:** we want to keep data realistic (e.g., `age` can't be negative).
*   **Code:** `age INT CHECK (age >= 18)`

### 6. DEFAULT
*   **Rule:** If we don't provide a value during insertion, MySQL uses this one.
*   **Use when:** Most records share a common starting state (e.g., a new user is 'Active' by default).
*   **Code:** `status VARCHAR(20) DEFAULT 'Active'`


```sql
CREATE TABLE employees (
    emp_id INT PRIMARY KEY,          -- Unique ID for everyone
    email VARCHAR(100) UNIQUE,       -- No two people can have the same email
    name VARCHAR(50) NOT NULL,       -- Everyone must have a name
    age INT CHECK (age >= 18),       -- No hiring minors
    department VARCHAR(50) DEFAULT 'General' -- Default team if not specified
);
```

**Why do we care?**
Without constraints, our database becomes a "garbage dump." Constraints ensure that wer data remains **clean, accurate, and useful** for wer applications.
