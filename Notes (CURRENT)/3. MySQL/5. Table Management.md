### 1. Create Table
*   **What:** Builds the blueprint for wer data.
*   **Why:** we can't store data until we define what columns exist and what rules they follow.
*   **Code:**
    ```sql
    CREATE TABLE employees (
        id INT PRIMARY KEY,
        name VARCHAR(50) NOT NULL,
        salary DECIMAL(10, 2)
    );
    ```

### 2. Drop Table
*   **What:** Completely destroys the table and all its data.
*   **Why:** To remove obsolete tables. **(Warning: This cannot be undone!)**
*   **Code:**
    ```sql
    DROP TABLE employees;
    ```

> [!NOTE]
> **Points to Note: **
> - **`DROP TABLE`**
>     - **Action:** Deletes the table structure and all data permanently.
>     - **Analogy:** Demolishing the entire building.
>     - **Result:** The table no longer exists in the database.
> - **`DELETE FROM table`**
>     - **Action:** Removes only the data (rows) but keeps the structure (columns/constraints).
>     - **Analogy:** Emptying the furniture from a building, leaving the walls standing.
>     - **Result:** The table remains empty but ready for new data.

### 3. Select

The `SELECT` statement is the most used command in SQL. It is how we **ask questions** to our database.
#### 1. The Basic Syntax
```sql
SELECT column1, column2 FROM table_name;
```

#### 2. Common Variations

###### Get Everything (`*`)
The asterisk is a wildcard that means "all columns."
```sql
SELECT * FROM students;
```

###### Get Specific Columns
Only retrieve what we need to keep things fast and clean.
```sql
SELECT name, age FROM students;
```

###### Filter Data (`WHERE`)
Only get rows that match a condition.
```sql
SELECT * FROM students WHERE age > 20;
```

###### Sort Results (`ORDER BY`)
Organize wer results (ASC = Ascending, DESC = Descending).
```sql
SELECT * FROM students ORDER BY name ASC;
```

###### Limit Results (`LIMIT`)
Useful for large tables when we just want a quick peek.
```sql
SELECT * FROM students LIMIT 5;
```

###### Remove Duplicates (`DISTINCT`)
Get only unique values from a column.
```sql
SELECT DISTINCT city FROM students;
```

#### 3. Aliases
we can give columns temporary names to make the output easier to read.
```sql
SELECT name AS Student_Name, age AS Student_Age FROM students;
```

### 4. Alter Table (The Renovation Toolkit)
Use `ALTER TABLE` when we need to change an existing table without deleting it.

##### A. Add Column
*   **What:** Adds a new field to the end of the table.
*   **Code:**
    ```sql
    ALTER TABLE employees ADD COLUMN email VARCHAR(100);
    ```

##### B. Drop Column
*   **What:** Permanently removes a column and its data.
*   **Code:**
    ```sql
    ALTER TABLE employees DROP COLUMN email;
    ```

##### C. Rename Column
*   **What:** Changes the name of a column.
*   **Code:**
    ```sql
    ALTER TABLE employees RENAME COLUMN salary TO monthly_pay;
    ```

##### D. Modify Column
*   **What:** Changes the data type, size, or constraints (like adding `NOT NULL`).
*   **Code:**
    ```sql
    -- Changing data type and size
    ALTER TABLE employees MODIFY COLUMN name VARCHAR(100); 
    
    -- Adding a constraint
    ALTER TABLE employees MODIFY COLUMN name VARCHAR(100) NOT NULL;
    ```

##### E. Add Constraint
*   **What:** Adds a rule (like a Check or Foreign Key) to an existing table.
*   **Code:**
    ```sql
    ALTER TABLE employees ADD CONSTRAINT chk_salary CHECK (monthly_pay > 0);
    ```

##### F. Rename Table
*   **What:** Changes the name of the entire table.
*   **Code:**
    ```sql
    ALTER TABLE employees RENAME TO staff;
    ```

### When to use What?
*   Use **`MODIFY`** if we only want to change the type/constraints but keep the same name.
*   Use **`CHANGE`** if we want to rename the column AND change its type at the same time:
    ```sql
    ALTER TABLE staff CHANGE monthly_pay salary DECIMAL(12, 2);
    ```
