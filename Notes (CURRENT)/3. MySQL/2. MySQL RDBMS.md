# What is RDBMS?

- RDBMS stands for Relational Database Management System.
- It is software that stores data in structured tables with rows and columns.
- It manages relationships between different tables using common fields.

# Why use RDBMS?

- It ensures data accuracy and consistency through strict rules.
- It allows efficient querying and retrieval of complex data sets.
- It supports multiple users accessing data simultaneously without conflicts.


# What is a Database Table?

- A table is a collection of related data organized in rows and columns.
- Each **column** represents a specific **attribute** or field of the data.
- Each **row** represents a single **record** or entry within that structure.

# What is a Relational Database?

- It is a database where data is stored in multiple interconnected tables.
- Tables are linked together using shared keys, such as primary and foreign keys.
- This structure reduces data redundancy and improves data integrity.

# When It Is a Good Choice
*   It is ideal for applications requiring strict data consistency and integrity, such as financial systems.
*   It suits structured data with clear relationships, like customer orders linked to inventory.
*   It works well for complex queries involving joins across multiple tables.
*   It is preferred when ACID (Atomicity, Consistency, Isolation, Durability) compliance is critical.

# When It Should Not Be Considered
*   It is not suitable for unstructured or semi-structured data, such as social media feeds or sensor logs.
*   It should be avoided when the data schema changes frequently and unpredictably.
