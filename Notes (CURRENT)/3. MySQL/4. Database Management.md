### 1. Create DB
*   **What:** Creates a new, empty container for our tables.
*   **Why:** To keep different projects or applications separate from each other.
*   **Code:**
    ```sql
    CREATE DATABASE my_project;
    ```
*   **Pro Tip:** Use `CREATE DATABASE IF NOT EXISTS my_project;` to avoid errors if it already exists.

### 2. Drop DB
*   **What:** Permanently deletes the entire database and every table inside it.
*   **Why:** To clean up old or test databases. **(Warning: This cannot be undone!)**
*   **Code:**
    ```sql
    DROP DATABASE my_project;
    ```

### 3. Other Essential DB Commands
*   **Show all Databases:** See what containers we currently have.
    ```sql
    SHOW DATABASES;
    ```
*   **Use a Database:** Tells MySQL which "container" we want to work in right now.
    ```sql
    USE my_project;
    ```

### The Great `DESC` Confusion

This is a very common point of confusion because the word `DESC` has two completely different meanings in MySQL depending on how we use it.

#### A. `DESC table_name` (Describe)
*   **Meaning:** "Show me the **blueprint**."
*   **Purpose:** To see the columns, data types, and constraints of a table.
*   **Output:** A list of fields (Field, Type, Null, Key, Default).
*   **Example:** `DESC students;`

#### B. `DESC TABLE table_name` (Explain)
*   **Meaning:** "Show me the **strategy**."
*   **Purpose:** To see how MySQL plans to execute a query (performance analysis). It is actually shorthand for `EXPLAIN SELECT * FROM table_name`.
*   **Output:** A plan showing access types (`ALL`, `ref`), keys used, and estimated rows.
*   **Example:** `DESC TABLE students;`

### Summary Table

| Command               | What it answers                     | When to use it                                       |
| :-------------------- | :---------------------------------- | :--------------------------------------------------- |
| `DESC students`       | "What columns are in this table?"   | When we forget the structure.                       |
| `DESC TABLE students` | "How will MySQL search this table?" | When wer query is slow and we need to optimize it. |
