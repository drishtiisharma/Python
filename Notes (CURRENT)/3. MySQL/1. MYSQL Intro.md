# Introduction to MySQL

MySQL is a very popular open-source relational database management system (RDBMS).

- MySQL is open-source
- MySQL is free
- MySQL is ideal for both small and large applications
- MySQL is very fast, reliable, scalable, and easy to use
- MySQL is cross-platform
- MySQL is compliant with the ANSI SQL standard
- MySQL was first released in 1995
- MySQL is developed, distributed, and supported by **Oracle Corporation**
- MySQL is named after co-founder Ulf Michael "Monty" Widenius's daughter: **My**

### Need of MySQL

- Replace inefficient flat-file storage (e.g., CSVs).
- Ensure data integrity, consistency, and complex relationships.
- Handle high-volume concurrent access and scalability for web apps.

### Where it is used?

- Web applications (WordPress, Joomla).
- E-commerce platforms (product/customer data).
- Data logging and analytics.
- Embedded systems and IoT devices.

### Why use it?

We use MySQL because it’s a **free, fast, and reliable** way to store organized data. It’s the go-to choice for websites because it’s easy to set up, works with almost every programming language, and keeps your information safe without costing a fortune.

Unlike many databases that force one way of storing data, MySQL lets you choose. You can use **InnoDB** for safe, transactional data (like banking) or **MyISAM** for faster, read-heavy tasks (like logging).

Others might be faster (Redis) or more flexible (MongoDB), but MySQL is the most **universally supported and "ready-to-go"** option for general-purpose applications.

MySQL guarantees that your data is always accurate and safe. It ensures that complex tasks, like processing a payment, are completed fully or not at all, so you never end up with missing or corrupted information.
### How it is used?

- Install server and client tools (e.g., MySQL Workbench).
- Design schema: `CREATE DATABASE` and `CREATE TABLE`.
- Manipulate data: `INSERT`, `SELECT`, `UPDATE`, `DELETE`.
- Connect via application drivers (Python, Java, PHP).

# Difference between MySQL & SQL

- **SQL**: A standardized **language** for querying databases.
- **MySQL**: A specific **software system** that uses SQL to manage data.
- **Analogy**: SQL is like English; MySQL is like a book written in English.
