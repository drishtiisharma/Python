# Multiprocessing

Multiprocessing allows a Python program to run multiple independent Processes concurrently.
Each process has its own memory space and can run on a separate CPU core, making it useful for CPU-intensive tasks.

It is commonly used when:
- A task requires significant CPU computation.
- Multiple independent tasks need to run at the same time.
- The program needs to use multiple CPU cores.
- A large task can be divided into smaller independent tasks.

```python
from multiprocessing import Process, current_process, cpu_count
import time

def eat(name):
    print("running process : ",current_process().name)
    print('started eating',name)
    time.sleep(3)
    print('finished eating',name)
 
def drink(name):
    print("running process : ",current_process().name)
    print('started drinking',name)
    time.sleep(3)
    print('finished drinking',name)

if __name__ == "__main__":
    p1 = Process(target=eat,args=('snacks',),name='eating')
    p2 = Process(target=drink,args=('cola',),name='drinking')

    p1.start()
    p1.join()
    p2.start()
    p2.join()

    print("total number of logical cpus : " ,cpu_count()) # returns the number of logical CPUs
```

## ProcessPoolExecutor

The **`ProcessPoolExecutor`** class in Python is part of the `concurrent.futures` module. It provides a high-level interface for **running CPU-bound tasks in parallel** across multiple system cores. By spawning separate Python interpreter instances as subprocesses, it effectively **bypasses the Global Interpreter Lock (GIL)**.

```python
from concurrent.futures import ProcessPoolExecutor
import time

def sq(num):
    time.sleep(3)
    return num * num

if __name__ == '__main__':
    with ProcessPoolExecutor(max_workers=2) as exe:

        f1 = exe.submit (sq,5)
        f2 = exe.submit (sq,2)

        print(f1.result())
        print(f2.result())
```

**Explanation**: This code creates a **pool of 2 processes** using `ProcessPoolExecutor`. `exe.submit(sq, 5)` sends `sq(5)` to one available process and returns a **Future** (`f1`) representing that task, while `exe.submit(sq, 2)` does the same for `sq(2)`. Both tasks can run concurrently, and each takes about 3 seconds because of `time.sleep(3)`. Finally, `f1.result()` and `f2.result()` wait for their respective tasks to finish and retrieve their returned values, **25 and 4**. The `with` block automatically manages the processes and waits for the submitted tasks to complete before exiting.

## Race Condition

A **race condition** happens when multiple processes access and modify the same shared resource at the same time, and the final result depends on the order in which they execute.

```python
from multiprocessing import Process, Value
import time

def withdraw(balance,amt):
    if balance.value>=amt:
        print("Balance available: ",balance.value)
        time.sleep(3)
        balance.value -=amt
        print("withdrawn: ",amt)
    else:
        print("balance cannot be 0")

if __name__ == '__main__':
    balance = Value('i',1000)

    p1 = Process(target=withdraw,args=(balance,700))
    p2 = Process(target=withdraw,args=(balance,700))
    
    # race condition
    p1.start()
    p2.start()

    p1.join()
    p2.join()

    print("final balance: ",balance.value) # returns -400
```

## Lock

A **Lock** ensures that only **one process at a time** can execute a particular section of code.

The protected section is called a **critical section**.

```
Process 1 → gets lock → modifies resource → releases lock
Process 2 → waits
Process 2 → gets lock → modifies resource → releases lock
```

```python
from multiprocessing import Process, Value, Lock
import time

def withdraw(balance,amt,lock):
    with lock:
        if balance.value >= amt:
            print("current balance: ",balance.value)
            time.sleep(3)

            balance.value -= amt
            print("withdrawn: ",amt)
        else:
            print("balance cannot be 0")

if __name__ == '__main__':
    
    balance = Value('i',1000)
    lock = Lock()

    p1 = Process(target=withdraw,args=(balance,700,lock))
    p2 = Process(target=withdraw,args=(balance,700,lock))

    p1.start()
    p2.start()

    p1.join()
    p2.join()

    print("final balance: ",balance.value)
```

**Explanation**: This code creates a **shared balance of ₹1000** using `Value` and a `Lock` to prevent both processes from accessing the balance at the same time. Two processes, `p1` and `p2`, each try to withdraw ₹700, but `with lock:` ensures that **only one process at a time** can check and modify the balance. The first process sees ₹1000 and withdraws ₹700, leaving ₹300; then the second process gets the lock, sees that ₹300 is less than ₹700, and cannot withdraw. Finally, `join()` makes the main process wait for both processes to finish, and the final balance is **₹300**.

## Semaphores

A **Semaphore** is similar to a Lock, but instead of allowing only **1 process**, you can allow a specific number of processes to access a resource simultaneously.

For example:

```
Semaphore(2)
```

means:

> Maximum **2 processes** can enter the protected section at the same time.

```python
from multiprocessing import Process, Semaphore
import time

def work(num,semaphore):
    with semaphore:
        print('Process',num,'started')
        time.sleep(3)
        print('Process',num,'finished')

if __name__ == '__main__':
    semaphore = Semaphore(4) # all 4 processes start together and end together

    processes = []

    for i in range(4):
        p = Process(target=work,args=(i,semaphore))
        p.start()
        processes.append(p)

    for p in processes:
        p.join()

# output:
# Process 0 started
# Process 1 started
# Process 2 started
# Process 3 started
# Process 0 finished
# Process 1 finished
# Process 2 finished
# Process 3 finished
```

## Event

**An `Event` is a synchronization mechanism that allows one process to notify other processes that a particular condition or action has occurred.** A process that calls `event.wait()` pauses until the event is set using `event.set()`. Once `set()` is called, the waiting process(es) are allowed to continue.

```python
from multiprocessing import Process, Event
import time

def worker1(event):
    print("worker 1 : doing some work...")
    time.sleep(3)
    print("worker 1 : work finished!")
    
def worker2(event):
    event.wait() # waits for signal
    print("worker 2 : doing some work...")
    print("worker 2 : work finished!")

if __name__ == "__main__":
    
    event = Event()

    p1 = Process(target=worker1,args=(event,))
    p2 = Process(target=worker2,args=(event,))

    p1.start()
    p2.start()
    p1.join()
    print("lets check")
    time.sleep(5)
    event.set() # sends the signal to continue
    p2.join()
```
