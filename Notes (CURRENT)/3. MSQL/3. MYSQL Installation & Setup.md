
# Download the Installer

### Download the Installer

- Visit the official MySQL Community Downloads page: [https://dev.mysql.com/downloads/installer/](https://dev.mysql.com/downloads/installer/)
- Select **mysql-installer-community** (larger file, includes all tools) or **web-community** (smaller, downloads components during install).
- Click "Download" and bypass the login prompt by clicking "No thanks, just start my download."

### Run the Installation Wizard

- Launch the downloaded `.msi` file.
- Choose **Developer Default** setup type to install Server, Workbench, Shell, and connectors.
- Click "Next" and then "Execute" to download and install all selected products.
