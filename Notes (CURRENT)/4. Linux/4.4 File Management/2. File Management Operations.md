Common File Management Operations include:

# Basic Commands

### 1. Listing Files (`ls`)
*Used to see what is inside a directory.*

*   **Basic List:** Shows files and folders with colors.
    *   `ls`
*   **Detailed List:** Shows permissions, owner, size, and date.
    *   `ls -l`
*   **Show Hidden Files:** Shows files starting with `.` (like config files).
    *   `ls -la`

### 2. Creating Files (`touch`)
*Used to make new empty files.*

*   **Create One File:** Makes a new blank file.
    *   `touch filename.txt`
*   **Create Multiple Files:** Makes several files at once.
    *   `touch file1.txt file2.txt`

### 3. Viewing Content (`cat`, `less`)
*Used to read what is inside a file.*

*   **Show All Content:** Prints the whole file on the screen (good for small files).
    *   `cat filename.txt`
*   **Page-by-Page View:** Lets you scroll through long files easily.
    *   `less filename.txt`

### 4. Copying Files (`cp`)
*Used to duplicate a file (original stays).*

*   **Copy to Folder:** Copies `file.txt` into the `backup` folder.
    *   `cp file.txt backup/`
*   **Copy & Rename:** Copies `file.txt` and names the copy `new_file.txt`.
    *   `cp file.txt new_file.txt`
*   **Copy Folder:** Copies a whole folder and its contents.
    *   `cp -r folder1/ folder2/`

### 5. Moving Files (`mv`)
*Used to change a file's location (cut and paste).*

*   **Move to Folder:** Moves `file.txt` into the `documents` folder.
    *   `mv file.txt documents/`

### 6. Renaming Files (`mv`)
*Used to change a file's name (same command as moving).*

*   **Rename File:** Changes `old_name.txt` to `new_name.txt`.
    *   `mv old_name.txt new_name.txt`

### 7. Deleting Files (`rm`)
*Used to remove files permanently.*

*   **Delete File:** Removes `file.txt` forever.
    *   `rm file.txt`
*   **Safe Delete:** Asks "Are you sure?" before deleting.
    *   `rm -i file.txt`
*   **Delete Folder:** Removes a folder and everything inside it.
    *   `rm -r foldername/`

### Quick Summary Table

# File Permission and Ownership

### 1. Permissions (Who can touch this?)

Linux protects files. We need to tell the system who is allowed to read or change them.

- **`chmod`**: Changes the "locks" on a file.
    - _Example:_ `chmod 777 file.txt` (Everyone can do everything—use carefully!)

**How are the numbers calculated?**
In Linux, every file has **3 types of permissions**:

1. **r (Read)** – To view the file.
2. **w (Write)** – To edit or change the file.
3. **x (Execute)** – To run the file (like a script or program).

Each permission is assigned a specific **Number Value** so we can add them up to create a code:

- **Read (r)** = **4**
- **Write (w)** = **2**
- **Execute (x)** = **1**

We simply **add** these values together to get the final permission code.

| Permission                               | Calculation | Number |
| ---------------------------------------- | ----------- | ------ |
| Read Only                                | 4           | **4**  |
| Read + Write                             | 4 + 2       | **6**  |
| Read + Execute                           | 4 + 1       | **5**  |
| All Permissions (Read + Write + Execute) | 4 + 2 + 1   | **7**  |
| No Permissions                           | 0           | **0**  |
- **`chown`**: Changes the "owner" of the file.
    - _Example:_ `sudo chown drishti file.txt` (Now I own it).

### 2. Searching (Where is it?)

When you have too many files, you use these to find things.

- **`find`**: Looks for a file by its **name**.
    - _Example:_ `find /home -name "photo.jpg"`
- **`grep`**: Looks for a **word** inside a file.
    - _Example:_ `grep "password" config.txt`

### 3. Zipping (Packing up)

Instead of sending 100 separate files, you pack them into one box.

- **`tar`**: The standard Linux way to zip folders.
    - _Pack it:_ `tar -czf backup.tar.gz my_folder/`
    - _Unpack it:_ `tar -xzf backup.tar.gz`

### 4. Shortcuts & Size

- **`ln -s`**: Creates a shortcut (like a Windows shortcut) so you don't have to copy the whole file.
    - _Example:_ `ln -s /long/path/file.txt my_link`
- **`du -sh`**: Tells you how big a folder is in MB or GB.
    - _Example:_ `du -sh Downloads/`
