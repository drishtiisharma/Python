# What is a Distribution?

A distribution (distro) is a complete, ready-to-use version of Linux.

The Linux kernel is only the core code that manages hardware. It cannot be used by itself because it has no interface or applications.

A distribution takes the Linux kernel and adds:

- A graphical desktop interface
- System tools and utilities
- A package manager for installing software
- Pre-installed applications like a web browser

Different distributions choose different combinations of these components.

Ubuntu includes the GNOME desktop and the APT package manager. 
Fedora includes the GNOME desktop but uses the DNF package manager.
Kali Linux includes security tools instead of standard office applications.

We download and install a distribution, not just the kernel.

# Linux Distributions

There are many other popular Linux distributions. Each is designed for different purposes.

- **Fedora** It is known for having the newest software features. It is often used by developers who want the latest tools. It is sponsored by Red Hat.

- **Debian** It is known for extreme stability and reliability. It changes very slowly to ensure nothing breaks. Ubuntu is actually built on top of Debian.

- **Kali Linux** It is designed specifically for cybersecurity and hacking tests. It comes pre-installed with hundreds of security tools. It is not meant for daily use like browsing or office work.

- **Linux Mint** It is designed to look and feel like Windows. It is very easy for beginners who are switching from Windows. It is based on Ubuntu but uses a different desktop interface.

- **Arch Linux** It is designed for advanced users who want to build their system from scratch. It does not come with any pre-installed software. You choose every single part of the system yourself.

- **CentOS Stream / Rocky Linux** These are designed for servers and enterprise businesses. They are built to be stable for years without needing frequent changes. They are often used for hosting websites and databases.
