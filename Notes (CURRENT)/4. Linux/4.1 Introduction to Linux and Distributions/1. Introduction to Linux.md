# What is a Kernel

Think of your computer as having two main parts: hardware and software.

Hardware includes the processor, memory, hard drive, keyboard, and screen. Software includes programs like web browsers and text editors.

The kernel sits between them. It is a bridge. It translates software requests into hardware actions.

Without a kernel, software cannot talk to hardware. You cannot save a file. You cannot display pixels. You cannot type on a keyboard.

# Linux is Just the Kernel

Linux is only this bridge component. It is not a complete product we can use directly.

Linux handles these specific tasks:

- Deciding which program uses the processor at any moment
- Allocating memory space for running programs
- Reading data from the hard drive
- Sending signals to the graphics card
- Receiving input from mouse and keyboard

Linux does not have windows. Linux does not have icons. Linux does not have a mouse cursor. Linux is invisible code running in the background.

# Why We Cannot Install "Just Linux"

If we download only the Linux kernel, we get a folder of code files. We cannot click anything. We cannot see anything. There is no interface.

We need additional software to make it usable. We need:

- A graphical interface with windows and buttons
- A file manager to browse folders
- A way to install new programs
- Basic tools like a text editor and terminal

# Ubuntu Packages Everything Together

Ubuntu takes the Linux kernel and adds all necessary components. It bundles them into one installable system.

Ubuntu includes:

- The Linux kernel (the bridge)
- GNOME desktop (windows, icons, menus)
- Files application (file browser)
- Terminal application (command line)
- Software Center (app store)
- Firefox web browser
- System settings panel

When you install Ubuntu, you install all these pieces at once. They work together as one system.
