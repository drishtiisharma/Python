# What are Directories?

A directory in Linux is a special type of file. Its only purpose is to store a **list of names of other files and folders**. It also stores information about those files, such as their **location** and **permissions**.
Every item in Linux is treated as a file. A directory is simply a file that contains a map of other files. It does not hold the actual data of your documents or programs. It only holds the references to them.

[Linux System Directories](https://blog.kubesimplify.com/img/blog/linux-system-directories-explained/7f_ypWYSW.png) are organized in a hierarchy. This means they are arranged in levels like a tree. The top level is called the root. Every other directory branches out from the root.

We use directories to organize our work. Instead of keeping all files in one place, we group them into folders. For example, we might have a directory for "Documents" and another for "Photos".

In Linux, there is no concept of separate drives like C: or D:. 
All directories exist under one single root directory represented by a forward slash (/).
