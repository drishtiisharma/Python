# Ways To Install Ubuntu

There are five primary ways to install Ubuntu:

**USB Installation** We write the Ubuntu system files onto a USB stick. We restart our computer and tell it to start from that USB stick. The installer copies Ubuntu onto our computer’s hard drive. This replaces our old system or sets up a new one.

**Dual Boot** We keep our current Windows system and add Ubuntu to the same hard drive. We split the hard drive space into two parts. When We turn on the computer, a menu asks if We want to use Windows or Ubuntu. Only one runs at a time.

**Virtual Machine** We install a program like VirtualBox on our current computer. Inside that program, We install Ubuntu. Ubuntu runs in a window like any other app. It uses our current computer’s resources but stays separate from our main system.

**WSL (Windows Subsystem for Linux)** We enable a specific feature in Windows settings. We download Ubuntu from the Microsoft Store. It gives us an Ubuntu command line inside Windows. We do not get a graphical desktop. We use it to run Linux commands while staying in Windows.

**Cloud Installation** We rent a virtual server from a provider like AWS or Azure. We select Ubuntu as the operating system when creating the server. The provider installs it for We automatically. We access it over the internet using a terminal.


## Steps to Installing WSL (Windows Subsystem for Linux)


### Enable Windows Features

1. Press the Windows key and type "Turn Windows features on or off".
2. Click the result to open the settings window.
3. Scroll down the list until we find **Virtual Machine Platform**.
4. Check the box next to it.
5. Scroll further to find **Windows Subsystem for Linux**.
6. Check the box next to it.
7. Click **OK** at the bottom of the window.
8. Wait for Windows to apply the changes.
9. Restart the computer when prompted.

### Install Ubuntu from Microsoft Store

1. Open the **Microsoft Store** app from wer Start menu.
2. Type "Ubuntu" in the search bar at the top.
3. Select the latest version, such as **Ubuntu 22.04 LTS**.
4. Click the **Get** or **Install** button.
5. Wait for the download and installation to finish.
6. Click **Open** or launch Ubuntu from wer Start menu.

### Final Setup

1. A terminal window will open automatically.
2. Wait for the message "Installing, this may take a few minutes...".
3. Enter a username when asked (use lowercase letters).
4. Enter a password when asked (we will not see characters as we type).
5. Re-enter the password to confirm.
6. we are now ready to use Ubuntu commands inside Windows.
