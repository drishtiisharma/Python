# WSL Management (Run in PowerShell)

- `wsl --install` downloads and installs the default Ubuntu distribution and enables all required Windows features automatically.
- `wsl --list --verbose` lists all installed Linux systems and their status.
- `wsl --shutdown` stops all running Linux systems to free memory.
- `wsl --update` updates the core WSL software provided by Microsoft.
- `wsl --unregister Ubuntu` deletes the Ubuntu system and all its data permanently.

# System Maintenance (Run in Ubuntu Terminal)

- `sudo apt update` refreshes the list of available software from repositories.
- `sudo apt upgrade` installs the latest versions of all currently installed software.
- `sudo apt install package_name` downloads and installs a specific new program.
- `sudo apt remove package_name` uninstalls a program but keeps its configuration files.


# 25 basic Ubuntu Commands

## Navigation Commands

|Command|Description|Example|
|---|---|---|
|`pwd`|Shows the current folder path.|`pwd`|
|`ls`|Lists files and folders in the current location.|`ls -l`|
|`cd`|Moves you to a different folder.|`cd Documents`|

## File Management Commands

|Command|Description|Example|
|---|---|---|
|`mkdir`|Creates a new empty folder.|`mkdir projects`|
|`touch`|Creates a new empty file.|`touch notes.txt`|
|`cp`|Copies a file or folder to a new location.|`cp file.txt backup.txt`|
|`mv`|Moves or renames a file or folder.|`mv old.txt new.txt`|
|`rm`|Deletes a file or folder permanently.|`rm file.txt`|

## File Viewing and Editing Commands

|Command|Description|Example|
|---|---|---|
|`cat`|Displays the entire content of a file.|`cat notes.txt`|
|`nano`|Opens a simple text editor to create or edit files.|`nano notes.txt`|
|`grep`|Searches for specific text inside a file.|`grep "error" log.txt`|

## System and Package Management Commands

|Command|Description|Example|
|---|---|---|
|`sudo`|Runs a command with administrator privileges.|`sudo apt update`|
|`apt-get`|Installs, updates, or removes software packages.|`sudo apt install git`|
|`dpkg`|Manages individual Debian package files (.deb).|`sudo dpkg -i app.deb`|
|`wget`|Downloads a file from the internet.|`wget https://example.com/file.zip`|

## Permissions and Ownership Commands

|Command|Description|Example|
|---|---|---|
|`chmod`|Changes who can read, write, or execute a file.|`chmod 755 script.sh`|
|`chown`|Changes the owner of a file or folder.|`sudo chown john file.txt`|

## System Information and Maintenance Commands

|Command|Description|Example|
|---|---|---|
|`tar`|Compresses or extracts multiple files into one archive.|`tar -cvf backup.tar folder/`|
|`uname`|Shows system details like kernel version.|`uname -r`|
|`date`|Displays the current date and time.|`date`|
|`shutdown`|Turns off or restarts the computer.|`sudo shutdown -h now`|
|`ps`|Lists currently running processes.|`ps aux`|
|`top`|Shows real-time system activity and resource usage.|`top`|
|`du`|Shows how much space a folder uses.|`du -sh /home`|
|`df`|Shows available disk space on all drives.|`df -h`|
