# What is Ubuntu

Ubuntu is a Linux-based operating system. It is designed for computers, smartphones, and network servers. The system is developed by a UK based company called Canonical Ltd. All the principles used to develop the Ubuntu software are based on the principles of Open Source software development.

# Features of Ubuntu

- Ubuntu is free to download and use without any license fees.

- It installs easily on most computers and detects hardware like Wi-Fi automatically.

- We install software safely from a trusted store instead of searching random websites.

- It receives regular security updates to protect our data from viruses and hackers.

- Ubuntu runs faster on older hardware because it uses fewer system resources than Windows.

- It is immune to most Windows viruses and malware, reducing the need for antivirus software.

- We have complete control over the system without forced updates or telemetry data collection.

- The terminal provides powerful automation tools that are more efficient than Windows PowerShell for many tasks.

- It is the standard operating system for cloud servers, so skills transfer directly to professional environments.
