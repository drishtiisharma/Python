# Introduction
## What is Python? 

Object Oriented High level programming language developed by ***GUIDO VAN ROSSUM*** in **1991**.

Known for its:
- Readability
- Wide and strong library support
- Easier to understand
- Used in data science, automation, AI, web development and more
- Object oriented
- Dynamic typing

**Libraries**:
- **Numpy**: numerical computing, arrays, matrices, mathematical operations
- **Pandas**: data manipulation, cleaning, analysis, dataframes
- **Polars**: alt to pandas, used for fast dataframe/data processing alternatives to pandas
- **Scipy**: scientific computing, optimization, statistics, linear algebra
- **Matplotlib**: basic data visualization and plotting
- **Beautfiful soup**: web scraping and HTML parsing
- **Pydantic**: data validation and structured data models
- **Tensorflow**: deep learning & neural networks
- **Opencv**: computer vision

**Frameworks**:
- **Django**: full stack web development
- **Flask**: lightweight web backend
- **Fastapi**: high performance API development

**Difference between library and framework**
- **Library**: collection of pre written helper functions, you call it when u need it
- **Framework**: comprehensive skeletal structure or blueprint, provides the overall foundation for building an application, calls your code and enforces a way of doing things

## Why Python?

- Works on different platforms (windows, mac, linux, raspberry pi, etc)
- Simpler syntax
- Quick prototyping – runs on an interpreter system, code can be executed as soon as its written

## Misc

**IDEs**
- Some IDEs: VS Code, Jupyter Notebook, PyCharm, Spyder, Google Colab, Python IDLE

**Indentation**
- Python relies on whitespaces for indentation.
- Other languages use curly braces `{}`.

**Unpacking**
- Python allows you to extract values from a list/tuple into variables.

**print()**
- `print()` is used to display text or output values.
- Quotes: Text is written inside quotes. You can use single (`' '`) or double (`" "`) quotes.
- By default, `print()` ends with a new line.
- To print multiple words on the same line, use `end=' '` inside `print()`.

**Compilation Error**
- Happens when a computer program cannot translate source code into an executable file because the code breaks the rules or structure of the programming language.
