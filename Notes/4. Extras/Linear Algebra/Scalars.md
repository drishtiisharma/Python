# Scalars

A scalar is a single number (real or complex). It has magnitude but no direction.

- Examples: 5, -3.2, π, 7i
- Used to scale vectors and matrices

**Why do we call it a scalar?**

Because it represents **magnitude only**.

For example:
> Temperature = 25°C

There is no direction involved.

Compare:
> Velocity = 25 m/s to the east

That has **magnitude + direction**, so it is represented by a vector.
