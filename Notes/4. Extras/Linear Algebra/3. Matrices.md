# Matrices

Matrices are rectangular arrays of numbers, symbols, or characters where all of these elements are arranged in each row and column.

- A [matrix](https://media.geeksforgeeks.org/wp-content/uploads/20250821114135656616/Matrix-in-maths.webp) is identified by its order, which is given in the form of rows ⨯ columns, and the location of each element is given by the row and column it belongs to.
- A matrix is represented as ([P]m⨯n), where P is the matrix, m is the number of rows, and n is the number of columns.

In mathematics, matrices are mainly used to represent and solve systems of linear equations, perform linear transformations, and study concepts like eigenvalues, determinants, and vector spaces.

[Matrix Representation](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcSXt9DG9hASOu4qVjeo0RmBlChIpl9SNYPet8XQ_XvPimnD-SBiAZdTp9dU&s=10)

## Order of Matrix

>Order of a Matrix = **Number of Rows** x **Number of Columns** 

Let's say if a matrix has 4 rows and 5 columns, then the order of the matrix will be 4⨯5.
Always remember that the **first** number in the order signifies the **number of rows** present in the matrix, and the **second** number signifies the **number of columns** in the matrix.

## Types of Matrices

**Row Matrix**: 
Only 1 row and 1+ columns.

**Column Matrix:** 
Only 1 column and 1+ rows.

**Horizontal Matrix:** 
Number of rows < Number of columns.

**Vertical Matrix:** 
Number of columns < Number of rows.

**Rectangular Matrix:** 
Number of rows != Number of columns.

**Square Matrix:** 
Number of rows == Number of columns.

**Diagonal Matrix:** 
A square matrix in which the non-diagonal elements are zero is called a diagonal matrix.

**Zero or Null Matrix:** 
A matrix whose all elements are zero is called a zero matrix aka Null Matrix.

**Unit or Identity Matrix:** 
A diagonal matrix whose diagonal elements are all 1 is called a unit matrix aka Identity Matrix and represented by I. 

**Symmetric matrix:** 
A square matrix where $A^T = A$. 

**Skew-symmetric Matrix:** 
A square matrix where $A^T = -A$.

**Orthogonal Matrix:** 
A matrix is said to be orthogonal if $AA^T = A^TA = I$.

**Idempotent Matrix:** 
A matrix is said to be idempotent if $A^2 = A$.

**Involutory Matrix:** 
A matrix is said to be involutory if $A^2 = I$. 

**Upper Triangular Matrix:** 
A square matrix in which **all the elements below the diagonal are zero** is known as the upper triangular matrix

**Lower Triangular Matrix:** 
A square matrix in which **all the elements above the diagonal are zero** is known as the lower triangular matrix

**Singular Matrix:** 
A square matrix is said to be a singular matrix if its determinant is zero, i.e., $|A|=0$.

**Non-singular Matrix:** 
A square matrix is said to be a non-singular matrix if its determinant is non-zero, i.e., $|A| != 0$.

## Rank of a Matrix

- Rank is the **count of linearly independent rows or columns.**
- It measures how many vectors cannot be formed by combining others.
- Rank ≤ min(number of rows, number of columns).
- For a square matrix, if the determinant ≠ 0, rank equals the matrix size.
- A zero matrix has a rank of 0.
- Denoted as ρ(A).

**2x2 Matrix Example**
Consider the matrix $A = \begin{pmatrix} 1 & 2 \\ 2 & 4 \end{pmatrix}$.
The second row $(2, 4)$ is exactly 2 times the first row $(1, 2)$. Because one row is a multiple of the other, they are linearly dependent. There is only **1** independent row. Therefore, the rank of $A$ is **1**.

Now consider $B = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$.
Neither row can be created from the other. They are linearly independent. Since there are **2** independent rows, the rank of $B$ is **2**.

**3x3 Matrix Example**
Consider the matrix $C = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 1 & 1 & 0 \end{pmatrix}$.
The third row $(1, 1, 0)$ is the sum of the first row $(1, 0, 0)$ and the second row $(0, 1, 0)$. This means the third row adds no new independent information. Only the first two rows are independent. Therefore, the rank of $C$ is **2**.

Now consider $D = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{pmatrix}$.
No row can be formed by combining the others. All three rows are linearly independent. Therefore, the rank of $D$ is **3**.

# General Importance

- They efficiently store and manage large datasets in rows and columns.
- hey provide a compact way to solve multiple linear equations simultaneously.
- They represent geometric changes like rotation, scaling, and translation in computer graphics and physics.
- They model connections in social networks, electrical circuits, and traffic flow.

# Quantum Perspective

- A quantum state (qubit) is represented as a column vector (an $n * 1$matrix)
- Physical actions like measurement or time evolution are represented by square matrices (operators) acting on state vectors.
- Matrix addition allows the representation of a particle being in multiple states at once.
- The tensor product of matrices describes how multiple particles correlate instantaneously across distances.
- The square of the magnitude of matrix elements determines the probability of finding a particle in a specific state.
