Type conversion

Can convert one type to another with int(), float(), complex() methods

Python has a built in module called random that can be used to make random numbers.

Object oriented language hence uses classes to define data types including its primitive datatypes.

Primitive : int, float, complex, bool, str, NoneType

Derived: list, tuple, set, frozenset, dict
Boolean : True or False. Bool() function allows us to evaluate any value and give True/False in return
