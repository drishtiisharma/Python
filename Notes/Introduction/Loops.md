# Loops

Loops
- While – can execute statements as long as the condition is true; keep in mind to increment ‘i”, or the loop will execute forever.
- For – used for iterative over a sequence (list, tuple, dictionary, set, string).

Range() function in for loop is used to loop through a set of code a specified no of times. Must always specify an ending value, starting value as needed. Specifiying increment value by using a third parameter is optional as well.

Else – with while & for statement, else can be used along with it once when the condition is no longer true/loop is finished. It will not be executed if the loop is stopped by a break statement.

Looping statements
- Break – skips the entire loop once when the condition is met(True)
- Continue – skips the current block of code but executes the remaining part of the loop
- Pass – when we need to write a statement syntactically and it cant be empty, we use “pass” to avoid getting an error ; or the part which we might want to change/update later ; is a null operation -> nothing happens when python executes it, serves as a placeholder.

Can be used with if-elif-else, while and for loops
Difference between pass and comments:
- Comments get ignored by python
- Pass is actual statement that gets executed
