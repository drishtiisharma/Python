# Statements
  
- A program is a list of “instructions” to be “executed” by a computer.
- These programming instructions are called statements.
- Statement ends when line ends.
- In python, semicolon(;) is not needed for that, unlikle some other languages.
- Executed in the order they are written.
- Syntactically legal(but unnecessary at most places), python treats it as a statement separator.
- Writing 2 statements in a row w/o a separator will give an error.
