# Collections

**Collections** are data types used to store **multiple values in a single variable**.

Python provides four main collection types:

|Collection|Syntax|Description|
|---|---|---|
|**List**|`[10, 20, 30]`|Ordered and mutable collection|
|**Tuple**|`(10, 20, 30)`|Ordered and immutable collection|
|**Set**|`{10, 20, 30}`|Unordered collection of unique values|
|**Dictionary**|`{'key': 'value'}`|Stores data as key-value pairs|

Collections make it easier to **store, organize, access, and manipulate multiple values**.

> The individual collection types — **[[List]], [[Tuple]], [[Set]], and [[Dictionary]]** — will be covered separately.
