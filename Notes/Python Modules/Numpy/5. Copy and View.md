# Difference between Copy and View

| **Copy**                                   | **View**                             |
| ------------------------------------------ | ------------------------------------ |
| Creates a new array                        | Creates a view of the original array |
| Owns its data                              | Does not own the data                |
| Changes do **not** affect original         | Changes **affect** original          |
| Changes to original do **not** affect copy | Changes to original **affect** view  |

NumPy provides two ways to handle data subsets: copies and views. 

A **copy** creates a completely independent array with its own memory allocation, ensuring that any modifications you make to it do not impact the original data. This is essential when we need to preserve the initial state of your dataset while performing experimental operations. 

In contrast, a **view** is merely a different window into the same underlying memory as the original array. It **does not store its own data**, making it highly memory-efficient for large datasets. However, because it shares memory, any change made to the view immediately reflects in the original array, and vice versa. 

We choose a copy when data isolation is required and a view when we want to manipulate specific parts of an array without duplicating memory usage.

##### Why use Views?

Views are used when we need to work with a specific subset of a large dataset without the memory overhead of creating a duplicate. If we have a massive array, making a full copy just to look at or modify a small section wastes significant RAM and processing time. 

A view allows us to isolate that section for focused operations while keeping the data linked to the original source. 

This is particularly useful for tasks like updating specific regions of an image or matrix in place, where you want the changes to persist in the main dataset immediately without the extra step of manually copying the results back.

### Creating Copy

```python
import numpy as np 
creating a copy
arr = np.array([10,20,30,'hello','how','are','you',12.3,15.68,True,False])

x = arr.copy()
while len(x)>3:
    x.pop()
print(x)
print(arr)
```

### Creating View

```python
a = np.array([10,20,30])

# changes in view affect the og array
print("before change in view,OG:",a)
b = a.view()
b[0] = 11
print("after change in view,OG:",a)

#changes in the og array affects the view
print("before changes in og array,VIEW:",b)
a[2] = 24
print("after changes in og array,VIEW:",b)
```

## Checking if Array owns its Data

Every NumPy array has the attribute `base` that returns `None` if the array owns the data.

Otherwise, the `base`  attribute refers to the original object.

```python
## checking if array owns its data
import numpy as np
z = np.array([10,210,30])
m = z.copy()
n = z.view()
print(m.base) # returns None
print(n.base)
```
